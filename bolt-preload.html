Bolt Preload and Torque — API 6A Annex H

(H.1) Tensile Stress Area: As = ¼ × π × [D − (0.9743 × P)]²
(H.2) Bolt Load: F = σ × As
(H.3) Make-up Torque: τ = { F·E·[P + (π·f·E / cos(π/6))] } ÷ { 2·[π·E − (P·f / cos(π/6))] } + F·f·[(H + D + K) / 4]
where P = 1 / threads per inch; H = 1.5·D + 0.125 in (hex size); K = 0.125 in (nut internal chamfer)
